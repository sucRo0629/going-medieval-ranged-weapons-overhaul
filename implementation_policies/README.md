# 実装方針ドキュメント

このディレクトリは、実装方針ドキュメントの集約先です。  
以後はこの配下を正本として参照します。

## 構成

- `ranged/`
  - 弓・クロスボウの方針群（入口 / 設計目標 / 実装状況）
- `melee_armor/`
  - 近接・投擲・防具・盾の方針群（入口 / 設計目標 / 実装状況）
- `core/`
  - 共通方針群（作成ポリシー / プレイテスト方針 / セッション早見）

## 参照ルール

- まず各カテゴリの「入口」ドキュメントを開く。
- 実装の正は常に `Data/Models/*.json` を優先する。
- 設計意図と実装状況が矛盾した場合、実装を正としてドキュメントを更新する。
